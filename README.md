# ML Study Lab

An interactive study website for **CS 460 (Machine Learning)** at Bellevue College. Every concept is explained with examples from the meal planner of my **CS 481** capstone project, "Diet Sucks: A meal planner that doesn't".

**Live site:** https://vyany-bc.github.io/study-sessions/

## Purpose
- Study machine learning for the CS 460 midterm with hands-on, meal-planner-based examples.
- Practice a professional Git and GitHub workflow (issues, branches, pull requests, merges) for my CS 481 individual skill-building report.

## Structure
| File | What it is |
|---|---|
| `index.html` | Home page with the list of chapters |
| `chapter-template.html` | Shared layout for every chapter |
| `assets/style.css` | Shared styles |

## Chapter template
1. Big idea
2. Meal planner example
3. Step-by-step calculation
4. Practice exercise with answer
5. Likely on the midterm

## Run locally
Download or clone the repository and open `index.html` in a browser. No build step is needed.

## Workflow
Every change follows the same cycle: issue, branch, commit, pull request, merge.

## Academic integrity
This repository contains study notes and practice examples only. Graded assignment solutions are not published here.
