Chapter 4: Information-Based Learning (Decision Trees)

How to build a decision tree by asking the most informative question first, using meals from the planner.

1. Big idea

A decision tree predicts a target by asking a series of questions about the features. The best first question is the one that tells us the most about the target. We measure that with entropy (how mixed a set is) and information gain (how much a question reduces the mixture). The ID3 algorithm builds the tree by choosing the feature with the highest information gain, splitting the rows, and repeating inside each group.

2. Meal planner example

The planner has to decide, for each recipe, Cook it this week? (Yes or No). Here are 10 recipes the planner has seen before. Each one is described by three features:

  • Prep time: Short or Long
  • Ingredients at home: Most or Few

3. Step-by-step calculation

Formulas.

  • Entropy: H(t, D) = - sum over levels l of P(t = l) * log2 P(t = l)
  • Remainder after splitting on a feature d: rem(d, D) = sum over values v of (|Dv| / |D|) * H(t, Dv)
  • Information gain: IG(d, D) = H(t, D) - rem(d, D)
  1. Entropy of the whole table. P(Yes) = 7/10 = 0.7 and P(No) = 3/10 = 0.3.
    H = -(0.7 * log2 0.7 + 0.3 * log2 0.3) = 0.8813 bits.
  2. Information gain of each feature on the whole table.

Check it with Python 
from math import log2
from collections import Counter

rows = [
    ("Short", "Most", "Cheap", "Yes"), ("Short", "Most", "Expensive", "Yes"),
    ("Short", "Few", "Cheap", "Yes"),  ("Short", "Few", "Expensive", "Yes"),
    ("Long", "Few", "Cheap", "No"),    ("Long", "Few", "Cheap", "No"),
    ("Long", "Most", "Cheap", "Yes"),  ("Long", "Most", "Cheap", "Yes"),
    ("Long", "Most", "Cheap", "Yes"),  ("Long", "Most", "Expensive", "No"),
]
features = ["Prep time", "Ingredients at home", "Cost"]

def entropy(labels):
    counts = Counter(labels)
    n = len(labels)
    return -sum(c / n * log2(c / n) for c in counts.values())

def info_gain(rows, i):
    n = len(rows)
    remainder = 0
    for value in set(r[i] for r in rows):
        part = [r[-1] for r in rows if r[i] == value]
        remainder += len(part) / n * entropy(part)
    return entropy([r[-1] for r in rows]) - remainder

print("H =", round(entropy([r[-1] for r in rows]), 4))
for i, name in enumerate(features):
    print(name, round(info_gain(rows, i), 4))

Expected output: H = 0.8813, Prep time 0.2813, Ingredients at home 0.0913, Cost 0.0016.

Other impurity measures

Information gain tends to favor features with many values. Two common fixes:

  • Gain ratio = information gain / split information, where split information = - sum (|Dv| / |D|) * log2(|Dv| / |D|).
  • Gini index = 1 - sum P(l)^2. A pure set has Gini 0.

Ingredients at home0.09130.97100.0940

With this table both measures agree: Prep time is the best root. The Gini index of the whole table is 1 - (0.72 + 0.32) = 0.42.

4. Practice exercise

Exercise A. Using the table above, what does the tree predict for a recipe with Long prep time, Few ingredients at home and Cheap cost?

Show answer

Prep time = Long, then Ingredients at home = Few, which is a leaf with No. The cost is not even asked. (This matches rows 5 and 6 of the table.)

Exercise B. Inside the Long branch (6 rows), compute the information gain of Cost and explain why ID3 does not choose it.

Show answer

Cheap: 5 rows (3 Yes, 2 No), H = 0.9710. Expensive: 1 row (0 Yes, 1 No), H = 0. Remainder = 5/6 * 0.9710 + 1/6 * 0 = 0.8091. Gain = 1 - 0.8091 = 0.1909. Ingredients at home has a higher gain (0.4591), so ID3 chooses it.

Exercise C. The planner receives a partition with 5 Yes and 5 No. What is its entropy? What would it be if all 10 rows were Yes?

Show answer

With 5 and 5: P = 0.5 and 0.5, so H = -(0.5 * log2 0.5 + 0.5 * log2 0.5) = 1 bit (the most mixed case for two levels). With 10 Yes: H = 0 (a pure set).

5. Likely on the midterm

  • Calculate entropy by hand: H = - sum P(l) * log2 P(l). Know the cases: pure set = 0, even two-level mix = 1.
  • Calculate information gain by hand: whole-table entropy minus the weighted entropy of the partitions.
  • Run ID3 by hand: choose the feature with the highest gain, split, and repeat in each partition without reusing that feature.
  • Know the three stopping cases: all rows have the same target (leaf), no features left (leaf with the majority), and an empty partition (leaf with the majority of the parent).
  • Know gain ratio and the Gini index, and why gain ratio is used (information gain favors features with many values).
  • Be able to say why a tree can overfit and what pruning does (replace a branch with a leaf).
