Chapter 4: Information-Based Learning (Decision Trees)

How to build a decision tree by asking the most informative question first, using meals from the planner.

1. Big idea

A decision tree predicts a target by asking a series of questions about the features. The best first question is the one that tells us the most about the target. We measure that with entropy (how mixed a set is) and information gain (how much a question reduces the mixture). The ID3 algorithm builds the tree by choosing the feature with the highest information gain, splitting the rows, and repeating inside each group.

2. Meal planner example

The planner has to decide, for each recipe, Cook it this week? (Yes or No). Here are 10 recipes the planner has seen before. Each one is described by three features:

  • Prep time: Short or Long

3. Step-by-step calculation

Formulas. Here \(t\) is the target, \(D\) is the set of rows, \(d\) is a feature, and \(D_{d=v}\) is the rows where feature \(d\) has value \(v\).

\[ H(t, D) = -\sum_{l \in \text{levels}(t)} P(t = l)\,\log_2 P(t = l) \] \[ \mathrm{rem}(d, D) = \sum_{v \in \text{levels}(d)} \frac{|D_{d=v}|}{|D|}\; H(t, D_{d=v}) \] \[ \mathrm{IG}(d, D) = H(t, D) - \mathrm{rem}(d, D) \]
  1. Entropy of the whole table. \(P(\text{Yes}) = 7/10 = 0.7\) and \(P(\text{No}) = 3/10 = 0.3\). \[ H(t, D) = -\left(0.7 \log_2 0.7 + 0.3 \log_2 0.3\right) = 0.8813 \text{ bits} \]
  2. Information gain of each feature on the whole table.

  4. Repeat inside the Long branch (6 rows, 3 Yes and 3 No, \(H = 1\)). Prep time is already used, so two features are left.

  5. Repeat inside Long and Most (4 rows: 3 Yes and 1 No, \(H = 0.8113\)). Only Cost is left, and it separates the rows perfectly (gain \(0.8113\)): Cheap gives Yes (3 rows) and Expensive gives No (1 row).

Check it with Python. The code below is editable: change it and press Run. Try changing the Cost of the last row to "Cheap" and see how the gains change.

from math import log2
from collections import Counter

rows = [
    ("Short", "Most", "Cheap", "Yes"), ("Short", "Most", "Expensive", "Yes"),
    ("Short", "Few", "Cheap", "Yes"),  ("Short", "Few", "Expensive", "Yes"),
    ("Long", "Few", "Cheap", "No"),    ("Long", "Few", "Cheap", "No"),
    ("Long", "Most", "Cheap", "Yes"),  ("Long", "Most", "Cheap", "Yes"),
    ("Long", "Most", "Cheap", "Yes"),  ("Long", "Most", "Expensive", "No"),
]
features = ["Prep time", "Ingredients at home", "Cost"]

def entropy(labels):
    counts = Counter(labels)
    n = len(labels)
    h = -sum(c / n * log2(c / n) for c in counts.values())
    return max(0.0, h)  # avoids printing -0.0 for a pure set

def info_gain(rows, i):
    n = len(rows)
    remainder = 0
    for value in set(r[i] for r in rows):
        part = [r[-1] for r in rows if r[i] == value]
        remainder += len(part) / n * entropy(part)
    return entropy([r[-1] for r in rows]) - remainder

print("H =", round(entropy([r[-1] for r in rows]), 4))
for i, name in enumerate(features):
    print(name, round(info_gain(rows, i), 4))

Expected output: \(H = 0.8813\), Prep time \(0.2813\), Ingredients at home \(0.0913\), Cost \(0.0016\).

Other impurity measures

Information gain tends to favor features with many values. Two common fixes:

  • Gain ratio: the information gain divided by the split information. \[ \mathrm{GR}(d, D) = \frac{\mathrm{IG}(d, D)}{\mathrm{SI}(d, D)}, \qquad \mathrm{SI}(d, D) = -\sum_{v} \frac{|D_{d=v}|}{|D|} \log_2 \frac{|D_{d=v}|}{|D|} \]
  • Gini index: a pure set has Gini 0. \[ \mathrm{Gini}(t, D) = 1 - \sum_{l \in \text{levels}(t)} P(t = l)^2 \]

With this table both measures agree: Prep time is the best root. The Gini index of the whole table is \(1 - (0.7^2 + 0.3^2) = 0.42\).

4. Practice exercise

Exercise A. Using the tree above, what does it predict for a recipe with Long prep time, Few ingredients at home and Cheap cost?

Show answer

Prep time is Long, then Ingredients at home is Few, which is a leaf with No. The cost is not even asked. (This matches rows 5 and 6 of the table.)

Exercise B. Inside the Long branch (6 rows), compute the information gain of Cost and explain why ID3 does not choose it.

Show answer

Cheap: 5 rows (3 Yes, 2 No), \(H = 0.9710\). Expensive: 1 row (0 Yes, 1 No), \(H = 0\).

\[ \mathrm{rem} = \tfrac{5}{6} \cdot 0.9710 + \tfrac{1}{6} \cdot 0 = 0.8091 \qquad \mathrm{IG} = 1 - 0.8091 = \mathbf{0.1909} \]

Ingredients at home has a higher gain (\(0.4591\)), so ID3 chooses it. Check it by running this code:

long_rows = [r for r in rows if r[0] == "Long"]
print("Cost:", round(info_gain(long_rows, 2), 4))
print("Ingredients at home:", round(info_gain(long_rows, 1), 4))

Exercise C. The planner receives a partition with 5 Yes and 5 No. What is its entropy? What would it be if all 10 rows were Yes?

Show answer

With 5 and 5: \(P = 0.5\) for each level.

\[ H = -\left(0.5 \log_2 0.5 + 0.5 \log_2 0.5\right) = \mathbf{1} \text{ bit} \]

This is the most mixed case for two levels. With 10 Yes the set is pure, so \(H = \mathbf{0}\). Check it:

print(entropy(["Yes"] * 5 + ["No"] * 5))
print(entropy(["Yes"] * 10))

5. Likely on the midterm

  • Calculate entropy by hand: \(H = -\sum_l P(l) \log_2 P(l)\). Know the cases: a pure set has \(H = 0\) and an even two-level mix has \(H = 1\).
  • Calculate information gain by hand: \(\mathrm{IG} = H(t, D) - \mathrm{rem}(d, D)\), the whole-table entropy minus the weighted entropy of the partitions.
  • Run ID3 by hand: choose the feature with the highest gain, split, and repeat in each partition without reusing that feature.
  • Know the three stopping cases: all rows have the same target (leaf), no features left (leaf with the majority), and an empty partition (leaf with the majority of the parent).
  • Know gain ratio and the Gini index, and why gain ratio is used (information gain favors features with many values).
  • Be able to say why a tree can overfit and what pruning does (replace a branch with a leaf).
